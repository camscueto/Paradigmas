# Paradigmas

## Programación Imperativa

Este proyecto presenta un ejemplo sencillo de Programación Imperativa utilizando Python.

### Algoritmo utilizado

Se implementó el algoritmo de **Ordenamiento Burbuja**, que organiza una lista de números de menor a mayor.

### Conceptos de Programación Imperativa utilizados

- Variables
- Ciclos `for`
- Condicionales `if`
- Modificación de datos
- Instrucciones ejecutadas paso a paso
- Entrada y salida de información

### Funcionamiento

El programa recibe una lista de números, compara los elementos consecutivos y los intercambia cuando están en el orden incorrecto.

Al finalizar, muestra la lista ordenada de menor a mayor.

### Archivo

- `ordenamiento.py`: contiene el código del algoritmo de ordenamiento burbuja.
